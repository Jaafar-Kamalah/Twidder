# Twidder

Twidder is a Single Page Web Application that I developed using:

* HTML, CSS, JavaScript
* Python, Flask
* SQLite
* HTTP/REST
* WebSockets
* JSON
* Gunicorn

A demo of the final app can be found at: https://youtu.be/rdfmVoP2jFE.

## Features

* User registration, login and logout
* User profiles and message walls
* Posting messages to other users
* Asynchronous HTTP communication using JSON
* Real-time communication using WebSockets
* Single active session per user
* Additional functionality and improvements from Lab 4

## How to run

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 server.py
```
